# 视觉主题系统

## 1. 整体视觉方向

### 调性定义
**工业台账**——这套系统服务于蜂蜡工厂的日常作业，界面应该像一本精心维护的账本：信息清晰、层级分明、操作确定、不浪费注意力。它不是展示型产品，是生产工具。

### 三个关键词
- **准确**：每个数字都能被看清，状态颜色不含糊
- **稳重**：页面结构固定可预期，仓管和财务打开就知道在哪里
- **在地**：颜色来自蜂蜡本身的材料世界——琥珀、原木、工厂哑光灰

### 不是什么
- 不是 SaaS 营销页（无渐变大图、无动画首屏）
- 不是微信小程序（不轻巧、不圆润）
- 不是通用后台模板（不用默认蓝色系）

## 2. 色彩系统

### 基础色板

| 角色 | 名称 | 色值 | 用途 |
|------|------|------|------|
| 背景主色 | Linen（亚麻白） | `#F5F3EF` | 页面底色，接近纸张，不刺眼 |
| 背景次色 | Paper（纸白） | `#FDFCFA` | 卡片、表单底色 |
| 主色 | Amber（琥珀） | `#C8860A` | 主按钮、激活导航、关键高亮 |
| 主色浅版 | Amber Light | `#FDF3DC` | 主色背景使用场景（标签、提示底色） |
| 强调色 | Iron（钢铁灰） | `#3D3D3D` | 表头、重要文字、导航底色 |
| 文字主色 | Ink（墨） | `#1A1A1A` | 正文、数字 |
| 文字次色 | Ash（灰） | `#6B6B6B` | 辅助说明、时间戳、标签 |
| 分割线 | Dust（浅灰） | `#E5E2DC` | 表格行分割、区块边界 |
| 成功色 | Grove（深绿） | `#2D6A4F` | 已结清、入库成功、正常状态 |
| 成功浅版 | Grove Light | `#D8EDDF` | 成功状态背景 |
| 错误色 | Brick（砖红） | `#B94040` | 超量错误、未结清、警告 |
| 错误浅版 | Brick Light | `#FAEAEA` | 错误状态背景 |
| 警示色 | Clay（土黄） | `#A05C1A` | 库存低位提醒、部分还款状态 |
| 警示浅版 | Clay Light | `#FFF0DC` | 警示状态背景 |

### 色彩使用规则

**主色（琥珀）** 只出现在：
- 主操作按钮（提交入库、提交出库、标记收款）
- 当前激活的导航项左侧竖线
- 可点击数字的 hover 下划线
- 进度指示器

**强调色（钢铁灰）** 只出现在：
- 左侧导航栏底色
- 表格表头背景

**禁止混用**：成功绿和主色琥珀不在同一个组件内同时出现。

### 应收账款欠款时长颜色规则（账龄着色）

欠款时间越长颜色越红，用于应收账款列表的金额列和天数列：

| 账龄 | 颜色名 | 色值 | 含义 |
|------|--------|------|------|
| < 15 天 | Clay（土黄） | `#A05C1A` | 刚产生，正常范围 |
| 15–30 天 | Clay Dark（深土黄） | `#8B3A10` | 需要关注，即将逾期 |
| > 30 天 | Brick（砖红） | `#B94040` | 逾期，需要催款 |

**规则说明：**
- 着色同时应用于金额和天数两列，保持视觉一致
- 应收账款列表默认按账龄降序排列（最久的排最前）
- 天数显示格式：`51天`（整数，不显示小数）
- 应付账款不使用此着色规则（付款主动权在己方）

### 对比度验证
- Ink `#1A1A1A` on Linen `#F5F3EF`：对比度 ≈ 16:1 ✓（AAA）
- Amber `#C8860A` on Paper `#FDFCFA`：对比度 ≈ 4.8:1 ✓（AA）
- Ink on Amber（按钮文字）：对比度 ≈ 8.5:1 ✓（AAA）

## 3. 字体系统

### 字体选择
| 角色 | 字体 | 说明 |
|------|------|------|
| 数字/英文 | `Tabular Lining`（IBM Plex Mono 或 DM Mono） | 等宽，数字对齐，财务数据必须 |
| 中文界面 | 系统中文字体栈 | `"PingFang SC", "Microsoft YaHei", sans-serif` |
| 代码/批次号 | IBM Plex Mono | 批次号、操作日志 |

> 说明：数字使用等宽字体是财务系统的硬要求，列里的金额才能垂直对齐。

### 字号比例

| 层级 | 用途 | 字号 | 行高 | 字重 |
|------|------|------|------|------|
| Display | 看板大数字（金额、余量） | 32px | 40px | 600 |
| Title 1 | 页面标题 | 22px | 32px | 600 |
| Title 2 | 卡片标题、区块标题 | 16px | 24px | 600 |
| Body | 表格内容、表单输入 | 14px | 22px | 400 |
| Caption | 辅助说明、时间戳、单位 | 12px | 18px | 400 |
| Label | 表单标签、表头 | 12px | 18px | 500 |

### 数字格式规范
- 金额统一显示到两位小数：`¥ 12,450.00`
- 千分位用逗号分隔
- 重量/数量跟单位紧挨：`850 kg`、`200 件`
- 负数/亏损用括号表示：`(¥ 320.00)`，颜色用砖红

## 4. 间距系统

使用 4px 为基础单位，所有间距均为其倍数。

### 间距规模

| 名称 | 值 | 用途 |
|------|----|------|
| space-1 | 4px | 图标与文字间距、标签内边距 |
| space-2 | 8px | 表单项内边距、行内元素间距 |
| space-3 | 12px | 表格行高补偿、小组件内边距 |
| space-4 | 16px | 卡片内边距、表单项间距 |
| space-5 | 24px | 卡片之间的间隔 |
| space-6 | 32px | 区块之间的间距 |
| space-7 | 48px | 页面顶部与内容区的距离 |

### 页面级布局间距

| 区域 | 值 |
|------|----|
| 左侧导航宽度 | 220px |
| 页面内容区左右内边距 | 32px |
| 页面内容区顶部内边距 | 32px |
| 卡片圆角 | 4px（轻微，不圆润） |
| 表格行高 | 48px |
| 表单输入框高度 | 40px |
| 主操作按钮高度 | 40px |

### 圆角策略
全局使用 `4px` 圆角——足够现代，不失工业感。对话框使用 `6px`。
标签/徽章使用 `2px`，强调信息的标牌感。
**不使用**大圆角（16px+）或完全圆形按钮。
