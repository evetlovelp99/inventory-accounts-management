# 核心组件规范

本文档定义系统中出现频率最高的 6 个组件。每个组件的设计决策必须与整体工业台账美学一致。

---

## 组件 1：数字卡片（StatCard）

### 用途
首页看板的核心单元，展示单个关键指标（库存余量、应收总额、本月收入等）。可点击下钻到对应列表。

### 视觉结构
```
┌────────────────────────────┐
│ 标签文字（Caption，Ash色）  │
│                            │
│ ¥ 128,450.00               │  ← Display 字号，Ink色，等宽字体
│                            │
│ 较上月 ▲ 12.3%  [单位/说明] │  ← Caption，可选
└────────────────────────────┘
```

- 底色：Paper `#FDFCFA`
- 边框：1px Dust `#E5E2DC`
- 圆角：4px
- 内边距：18px 18px 16px
- 阴影：无（扁平，与工业台账调性一致）

**等高要求（重要）**：同行的多张 StatCard 必须等高。实现方式：
- 父容器使用 `display: grid; align-items: stretch`
- 每张卡片使用 `display: flex; flex-direction: column; justify-content: space-between`
- 禁止用固定高度——卡片高度由同行最高的那张自然撑开决定
- 标签文字必须单行显示（`white-space: nowrap`），避免某张卡因换行导致不等高

### 状态

| 状态 | 视觉变化 |
|------|----------|
| 默认 | 如上描述 |
| Hover（可点击时） | 边框变为 Amber `#C8860A`，cursor: pointer |
| 警告（余量不足、欠款超期） | 左侧 4px Brick 红色竖线，标签文字变砖红 |
| 正常/已结清 | 左侧 4px Grove 绿色竖线（可选，不强制） |
| 加载中 | 整块替换为骨架屏（灰色矩形动画） |
| 无数据 | 数字位置显示 `—`，Ash 色 |

### 交互行为
- 点击整张卡片跳转到对应详细列表
- 不使用独立的"查看详情"链接，整卡可点

## 组件 2：数据表格（DataTable）

### 用途
库存列表、账款列表、流水记录——系统中信息密度最高的展示方式。

### 视觉结构
```
┌──────┬──────────┬────────┬────────┬──────────┐
│ 产品 │ 当前余量  │ 单位   │ 采购价  │ 最后入库  │  ← 表头行
├──────┼──────────┼────────┼────────┼──────────┤
│ 精蜡 │ 850      │ kg     │ ¥18.50 │ 06-18    │
├──────┼──────────┼────────┼────────┼──────────┤
│ 粗蜡 │ 0        │ kg     │ ¥12.00 │ 06-10    │  ← 零库存警告行
└──────┴──────────┴────────┴────────┴──────────┘
```

- 表头：底色 `#F0EDE8`（Linen 加深一档），文字 Label 字号 500 字重，Ink 色
- 数据行：底色交替（奇数 Paper，偶数 `#F9F7F4`）
- 行高：48px
- 行分割线：1px Dust
- 数字列：右对齐，等宽字体
- 文字列：左对齐

### 列宽策略
- 固定宽度列：操作列（80–100px）、日期列（100px）、状态列（90px）
- 弹性宽度列：名称类字段自动填充剩余空间
- 金额列：固定 120px，右对齐

### 状态行样式

| 行状态 | 视觉变化 |
|--------|----------|
| 正常 | 如上默认 |
| Hover | 整行背景变 `#F0EDE8`，cursor 根据是否可点击决定 |
| 选中（可多选时） | 行背景 Amber Light `#FDF3DC`，左侧 3px 琥珀竖线 |
| 警告（库存为零/逾期） | 整行文字变 Brick `#B94040`，不变背景（避免视觉噪音） |
| 成功（已结清） | 状态列显示绿色标签，行文字不变 |

### 操作列
- 操作按钮默认隐藏，行 hover 时出现
- 操作项：文字链接样式（不用按钮形状），如「查看」「标记收款」「修改」
- 危险操作（删除）：砖红色文字，点击需二次确认

### 空状态
- 表格区域垂直居中，48px 线条图标 + 说明文字 + 操作入口
- 不显示空行，不显示表头（避免给人"加载中"的误解）

### 工具栏规范

**搜索框**
- 宽度：220px，高度 36px，左侧搜索图标，圆角 4px
- 清除按钮：输入内容时右侧出现 ✕ 图标按钮，点击清空输入并重新过滤；无内容时隐藏
- Focus 样式：边框变 Amber `#C8860A`，外发 3px Amber Light `#FDF3DC` 光晕

**日期范围筛选**
- 位于工具栏第二行，标签「最后更新日期：」+ 开始日期输入 + 分隔符「—」+ 结束日期输入
- 开始/结束日期可单独填写，也可组合使用
- 与搜索框、状态筛选同时生效（AND 逻辑）

**筛选标签（Filter Tag）**
- 有激活的筛选条件时，在工具栏第二行右侧显示对应 tag
- 每个 tag 格式：`[筛选类型：筛选值  ✕]`
- tag 样式：Amber Light `#FDF3DC` 底色，Amber 文字，1px Dust 边框，2px 圆角
- 点击 tag 内的 ✕ 单独关闭该条件
- 多个 tag 时末尾显示「清除全部」文字链接（灰色，hover 变砖红）
- 无筛选条件时 tag 区域不占空间

**导出按钮**
- 有任意筛选条件激活时：导出当前筛选结果，Toast 提示「已导出 N 条记录（当前筛选结果）」
- 无筛选条件时：导出全部数据，Toast 提示「已导出 N 条记录（全部）」
- Toast 3 秒后自动消失

## 组件 3：录入表单（EntryForm）

### 用途
入库录入、出库录入——仓管最频繁使用的操作界面，必须高效、防错。

### 视觉结构
```
[字段标签 *必填]
[────────────────────────────]  ← 输入框

[字段标签]          [字段标签]
[────────────]      [────────────]  ← 两列并排

┌──────────────────────────────┐
│ 本批总金额（自动计算）          │  ← 计算结果区，浅底色
│ ¥ 12,450.00                  │
└──────────────────────────────┘

                [取消]  [提交入库 →]
```

### 字段组件规范

**输入框（Input）**
- 高度：40px
- 边框：1px Dust `#E5E2DC`，圆角 4px
- Focus 边框：1px Amber `#C8860A` + `box-shadow: 0 0 0 3px #FDF3DC`（琥珀光晕）
- 错误边框：1px Brick `#B94040` + 红色光晕
- 底色：Paper `#FDFCFA`
- 占位符：Ash 色，14px

**下拉选择（Select）**
- 与输入框同高同样式
- 右侧箭头图标：Ash 色
- 下拉列表：Paper 底色，1px Dust 边框，行高 40px
- 搜索过滤：选项超过 8 个时在下拉内置搜索框

**日期选择（DatePicker）**
- 默认显示今天日期
- 点击弹出日历面板（轻量，不复杂）
- 面板激活日：Amber 底色

**只读计算字段**
- 底色：`#F0EDE8`（区别于可编辑字段）
- 字体：等宽，Display 或 Title 2 字号，加粗
- 标签说明：Caption，Ash 色
- 无边框，无 Focus 态

### 多行批次录入（出库专用）

出库表单中「批次明细」区域支持添加多行，每行对应一个入库批次的出库量，用于跨批次混发场景。

**整体结构**
```
批次明细 *
出库成本按所选批次的采购单价计算

┌──────────────────────────────────────────────────────┐
│ [批次下拉选择]            [数量输入]      [× 删除行]  │  ← 行 1
│ 入库日期 06-10 · 采购价 ¥18.50/kg · 余量 350 kg      │
├──────────────────────────────────────────────────────┤
│ [批次下拉选择]            [数量输入]      [× 删除行]  │  ← 行 2
│ 入库日期 06-21 · 采购价 ¥18.50/kg · 余量 500 kg      │
└──────────────────────────────────────────────────────┘
[+ 添加批次]
```

**行样式**
- 每行底色：Paper `#FDFCFA`，边框 1px Dust，圆角 4px，内边距 12px 14px
- 选中批次后行底展示该批次信息（日期、采购价、可用余量），Caption 字号，Ash 色
- 删除按钮（×）：默认 Ash 色，hover 变 Brick 红，至少保留一行时第一行删除按钮禁用

**批次下拉**
- 下拉选项格式：`批次号 — 余量 XXX 单位 — 采购价 ¥XX`
- 已在其他行选中的批次：在下拉中置灰不可再选（防止同批次重复添加）

**行内超量校验**
- 输入数量超过该批次余量时：数量输入框变红色错误边框，行底显示红色错误提示
- 错误提示格式：`⚠ 不能超过该批次余量 350 kg`
- 不阻止继续填写其他行，但提交时整体拦截

**「+ 添加批次」按钮**
- 样式：Secondary 按钮，高度 36px，左侧 + 图标
- 位置：批次行列表正下方，左对齐
- 所有批次余量均已用完时按钮禁用，提示「该产品所有批次已添加」

**汇总计算区**
- 位于批次明细区下方，只读浅底色块
- 显示：总出库数量 / 总销售额 / 加权采购成本 / 预估总毛利
- 毛利为正显示 Grove 绿色，为负显示 Brick 红色


- 字号：12px Label
- 字重：500
- 颜色：Ink `#1A1A1A`
- 必填标识：红色 `*` 跟在标签后
- 标签在字段上方（不在左侧），间距 6px

### 错误提示
- 位置：字段正下方，间距 4px
- 字号：12px Caption
- 颜色：Brick `#B94040`
- 图标：⚠ 小图标在文字左侧
- 示例：`⚠ 出库数量不能超过当前余量 850 kg`

### 表单提交状态
| 状态 | 提交按钮变化 | 其他 |
|------|------------|------|
| 正常可提交 | Amber 底色，Ink 文字 | — |
| 有错误 | 灰色禁用 | 错误字段高亮 |
| 提交中 | 灰色 + "提交中…" | 所有字段禁用 |
| 提交成功 | 页面跳转回列表 | 顶部成功提示条 |
| 提交失败 | 恢复可点击 | 顶部错误提示条 |

## 组件 4：状态标签（StatusBadge）

### 用途
在表格、卡片、详情页中标注记录的当前状态——账款是否结清、库存是否充足、记录类型（入库/出库）。

### 视觉结构
```
[● 已结清]   ← 绿色圆点 + 绿色文字 + 绿色浅底
[● 未结清]   ← 砖红圆点 + 砖红文字 + 砖红浅底
[● 部分还款] ← 土黄圆点 + 土黄文字 + 土黄浅底
[入 库]      ← 仅用于流水类型，无圆点，矩形标签
[出 库]      ← 同上
```

### 尺寸
- 内边距：3px 8px
- 圆角：2px（标牌感，不用大圆角）
- 字号：12px
- 圆点：6px，inline，左距文字 4px

### 色彩对照表

| 标签内容 | 底色 | 文字色 | 圆点色 |
|----------|------|--------|--------|
| 已结清 | Grove Light `#D8EDDF` | Grove `#2D6A4F` | Grove |
| 未结清 | Brick Light `#FAEAEA` | Brick `#B94040` | Brick |
| 部分还款 | Clay Light `#FFF0DC` | Clay `#A05C1A` | Clay |
| 入库 | Amber Light `#FDF3DC` | Amber `#C8860A` | — |
| 出库 | `#EDF2FF`（淡蓝） | `#3B5BDB`（深蓝） | — |
| 还款记录 | `#F3F0FF`（淡紫） | `#6741D9`（深紫） | — |

> 注：入库/出库/还款用于流水类型区分，与账款状态的颜色系统不重叠。

## 组件 5：操作按钮（Button）

### 类型与用途

| 类型 | 场景 | 样式 |
|------|------|------|
| Primary | 主操作：提交入库、提交出库、标记收款 | 琥珀底色 + Ink 文字 |
| Secondary | 次要操作：导出、筛选、查看详情 | 白色底色 + Ink 文字 + Dust 边框 |
| Danger | 危险操作：删除记录 | 白色底色 + Brick 文字 + Brick 边框 |
| Ghost | 取消、返回 | 无底色无边框 + Ash 文字 |
| Link | 表格内行操作（如"标记收款"） | 无底色无边框 + Amber 文字 + hover 下划线 |

### 尺寸
- 高度：40px（标准），32px（紧凑，用于表格内）
- 内边距：标准 0 20px，紧凑 0 12px
- 圆角：4px
- 字号：14px，字重 500

### 状态

| 状态 | Primary | Secondary |
|------|---------|-----------|
| 默认 | `#C8860A` 底 | 白色底 + Dust 边框 |
| Hover | `#A06A08`（加深 15%） | Linen 底 `#F5F3EF` |
| Active（按下） | `#7A5006`（加深 30%） | Dust 底 |
| 禁用 | `#E5E2DC` 底 + Ash 文字 | 同左，opacity 0.5 |
| 加载中 | 文字替换为"处理中…"，禁用点击 | — |

### 按钮组规则
- 同一区域内最多一个 Primary 按钮
- 按钮组排列：Ghost/Secondary 在左，Primary 在右
- 危险操作单独放置，与普通操作保持距离（至少 16px）

## 组件 6：全局提示条（Toast / AlertBar）

### 用途
操作反馈——录入成功、提交失败、网络错误。不打断用户流程，几秒后自动消失（或需主动关闭）。

### 两种形式

**Toast（轻量，操作成功反馈）**
- 位置：页面右上角，距顶 72px（TopBar 下方），距右 24px
- 宽度：最大 360px，自适应内容
- 底色：Ink `#1A1A1A`（深色，确定感）
- 文字：白色，14px
- 左侧图标：✓ 成功 / ✕ 失败
- 持续时间：成功 3 秒自动消失，失败不自动消失，需手动关闭
- 圆角：4px
- 示例：`✓ 入库记录已保存，库存已更新`

**AlertBar（全局警告，错误较严重时）**
- 位置：TopBar 正下方，贯穿内容区顶部
- 底色：Brick Light `#FAEAEA`，左侧 4px Brick 竖线
- 文字：Brick 色，14px
- 右侧关闭按钮
- 示例：`⚠ 服务器连接失败，数据暂未保存，请检查网络后重试`

### 叠加规则
- Toast 最多同时显示 3 条，从上到下叠放，间距 8px
- 新 Toast 从右侧滑入，消失时向右淡出（简单动画，不过度）
- AlertBar 同时只显示一条，新的替换旧的

## 组件使用优先级总结

| 页面 | 主要组件 |
|------|---------|
| 首页看板 | StatCard × 4–6，DataTable（最近动态） |
| 库存总览 | DataTable，StatusBadge，Button（筛选/导出） |
| 录入入库/出库 | EntryForm，Button（Primary+Ghost） |
| 应收/应付账款 | DataTable，StatusBadge，Button（标记收款） |
| 操作反馈 | Toast（成功），AlertBar（错误） |
