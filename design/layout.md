# 布局系统

## 1. 整体布局结构

### 桌面端主框架（≥ 1024px）

```
┌─────────────────────────────────────────────────────┐
│  顶部栏 TopBar（高度 56px，贯穿全宽）                    │
├──────────────┬──────────────────────────────────────┤
│              │                                      │
│  左侧导航     │  内容区 Content Area                  │
│  SideNav     │                                      │
│  220px       │  padding: 32px                       │
│              │                                      │
│              │                                      │
│              │                                      │
└──────────────┴──────────────────────────────────────┘
```

**左侧导航（SideNav）**
- 固定宽度 220px，不可折叠（MVP 阶段）
- 底色：Iron `#3D3D3D`（深灰，与内容区形成分隔）
- 高度：撑满视口，不随页面滚动
- 激活项：左侧 3px 琥珀色竖线 + 文字变亮
- 导航层级：一级（模块）+ 二级（子功能）

**顶部栏（TopBar）**
- 高度 56px，底色 Paper `#FDFCFA`，底部 1px Dust 分割线
- 左：当前页面标题（Title 1）
- 右：当前登录用户名 + 角色标签 + 退出按钮

**内容区（Content Area）**
- 左侧留出 220px 导航宽度
- 内边距：上下左右均 32px
- 最大内容宽度：1200px（超宽屏居左对齐，不居中撑满）
- 底色：Linen `#F5F3EF`

## 2. 内容区内部布局模式

### 模式 A：看板布局（首页使用）

```
┌─────────────────────────────────────────┐
│  页面标题                                │
├──────────┬──────────┬──────────┬────────┤
│  数字卡片 │  数字卡片 │  数字卡片 │ 数字卡片│  ← 4列等宽
├──────────┴──────────┴──────────┴────────┤
│                                         │
│  库存概况区（表格或卡片列表）              │
│                                         │
├─────────────────────┬───────────────────┤
│  账款概况区          │  最近动态区        │  ← 左6右4比例
└─────────────────────┴───────────────────┘
```

- 4 列数字卡片：使用 CSS Grid，`grid-template-columns: repeat(4, 1fr)`，gap: 24px
- 下方两列：左侧 60%，右侧 40%，gap: 24px
- 移动端：全部折叠为单列

### 模式 B：列表布局（库存查询、账款列表使用）

```
┌─────────────────────────────────────────┐
│  页面标题            [筛选栏] [主操作按钮] │
├─────────────────────────────────────────┤
│  表格（占满内容区宽度）                   │
│                                         │
│                                         │
├─────────────────────────────────────────┤
│  分页控件                               │
└─────────────────────────────────────────┘
```

- 表格占满内容区，不定义最大宽度
- 筛选栏和主操作按钮在同一行：筛选组件靠左，按钮靠右
- 表格行可点击，hover 变色

### 模式 C：录入表单布局（入库/出库录入使用）

```
┌─────────────────────────────────────────┐
│  页面标题                                │
├─────────────────────────────────────────┤
│  ┌───────────────────────────────────┐  │
│  │  表单卡片（最大宽度 640px，居左）    │  │
│  │                                   │  │
│  │  [字段标签]                        │  │
│  │  [输入框]                          │  │
│  │                                   │  │
│  │  [字段标签]   [字段标签]            │  │
│  │  [输入框]     [输入框]              │  ← 部分字段两列
│  │                                   │  │
│  │  ────────── 自动计算结果 ────────── │  │
│  │  本批总金额：¥ 12,450.00           │  │
│  │                                   │  │
│  │  [取消]      [提交入库]             │  │
│  └───────────────────────────────────┘  │
└─────────────────────────────────────────┘
```

- 表单卡片固定最大宽 640px，左对齐（不居中）
- 单列字段：产品名称、备注（需要宽度）
- 双列字段：数量 + 单价，日期 + 供应商（短字段并排）
- 自动计算区用浅底色块区分，不是可编辑字段
- 按钮组：取消（次要）+ 提交（主要），靠右对齐

## 3. 导航结构详细规范

### 左侧导航内容

```
[工厂 LOGO 或系统名称]
─────────────────────
▸ 首页看板

▸ 仓库管理
  ├── 录入入库
  ├── 录入出库
  └── 当前库存

▸ 财务管理
  ├── 应收账款
  └── 应付账款

─────────────────────
▸ 系统设置（仅老板可见）
  ├── 产品管理
  ├── 用户管理
  ├── 客户管理
  └── 供应商管理
```

- 模块标题：大写字母 + 12px Label 字号，Ash 色，不可点击
- 子项：14px Body，默认 `#B0ADA8`（导航底色上的浅色文字）
- 激活子项：`#FFFFFF` 文字 + 左侧 3px `#C8860A` 竖线
- 模块 hover：整行背景变 `rgba(255,255,255,0.08)`

## 4. 响应式行为

### 断点定义

| 断点 | 宽度 | 说明 |
|------|------|------|
| Desktop | ≥ 1024px | 主要使用场景，侧边栏展开 |
| Tablet | 768px – 1023px | 侧边栏可收起为图标导航 |
| Mobile | < 768px | 底部 Tab 导航，当前 MVP 不强制支持 |

> MVP 阶段：重点保证桌面端（≥ 1024px）。平板简单适配即可，移动端不在 MVP 范围。

### 桌面端（≥ 1024px）
- 完整三栏布局（TopBar + SideNav + Content）
- 看板 4 列数字卡片
- 表格显示全部列

### 平板端（768px – 1023px）
- SideNav 收起为 64px 宽图标栏，hover 展开浮层
- 看板数字卡片变为 2 列
- 表格隐藏次要列（备注、最后更新时间）
- 表单仍使用单列布局

### 移动端（< 768px，后续版本）
- SideNav 替换为底部 Tab Bar（4 个主入口）
- 所有表格变为卡片列表
- 看板数字卡片 2×2 网格

## 5. 页面滚动策略

- **TopBar**：固定在顶部，不随内容滚动
- **SideNav**：固定在左侧，不随内容滚动
- **内容区**：可垂直滚动
- **表格**：内容区宽度不足时，表格横向滚动（不压缩列宽）
- **录入表单**：提交按钮始终可见（跟随页面，不 sticky）

---

## 6. 空状态与加载状态布局

### 空状态
- 位置：列表/表格区域的正中央
- 内容：图标（简单线条图）+ 说明文字 + 可选操作按钮
- 图标尺寸：48px
- 说明文字：Caption 字号，Ash 颜色

### 骨架屏（加载中）
- 数字卡片：整块矩形占位，灰色动画
- 表格行：每行用条形占位，宽度随机 60%–90%（显得自然）
- 不使用旋转 Spinner（太随意），用骨架屏更稳重
