# Feature: 系统设置（产品 / 用户 / 客户 / 供应商）

## Goal
让老板能维护系统内的产品品类、用户账号、客户信息和供应商信息，确保录入流程中的下拉选项准确、角色权限清晰。

---

## 子模块一：产品管理

### User Flow
1. 老板进入「系统设置」→「产品管理」
2. 查看现有产品列表（产品名、规格/单位、状态）
3. 点击「新增产品」→ 填写产品名称、规格、计量单位（如：公斤、桶）→ 保存
4. 可编辑已有产品名称和单位（不影响历史记录）
5. 停用某产品（不再出现在录入选择中，但历史数据保留）

### 字段
| 字段 | 类型 | 必填 |
|------|------|------|
| 产品名称 | 文本 | ✓ |
| 规格 | 文本 | — |
| 计量单位 | 文本（如：kg、桶） | ✓ |
| 状态 | 启用 / 停用 | ✓ |

### States
| 场景 | 状态 |
|------|------|
| 列表为空 | 提示"暂无产品，请先新增" |
| 保存成功 | 提示"已保存" |
| 产品名重复 | 错误"已存在同名产品，请修改名称" |
| 停用有库存的产品 | 警告"该产品仍有余量，停用后将不再显示在录入选项中，是否继续？" |

---

## 子模块二：用户管理

### User Flow
1. 老板进入「系统设置」→「用户管理」
2. 查看所有账号列表（姓名、角色、账号、状态）
3. 新增用户：填写姓名、登录账号、初始密码、分配角色
4. 修改用户角色或停用账号

### 字段
| 字段 | 类型 | 必填 |
|------|------|------|
| 姓名 | 文本 | ✓ |
| 登录账号 | 文本 | ✓ |
| 初始密码 | 文本 | ✓ |
| 角色 | 老板 / 财务 / 仓管 / 主管 | ✓ |
| 状态 | 启用 / 停用 | ✓ |

### 角色说明
| 角色 | 说明 |
|------|------|
| 老板 | 全部权限，含系统设置 |
| 财务 | 账款管理、查看库存、导出对账单 |
| 仓管 | 入库/出库录入、查看库存 |
| 主管 | 只读，查看库存和账款 |

### States
| 场景 | 状态 |
|------|------|
| 账号重复 | 错误"该账号已存在" |
| 停用自己 | 禁止操作，提示"无法停用当前登录账号" |

## 子模块三：客户管理

### User Flow
1. 老板进入「系统设置」→「客户管理」
2. 查看客户列表（客户名、国家/地区、联系人、状态）
3. 点击「新增客户」→ 填写信息 → 保存
4. 可编辑已有客户信息（不影响历史出库记录）
5. 停用客户后，不再出现在出库录入的客户下拉选项中，历史数据保留

### 字段
| 字段 | 类型 | 必填 |
|------|------|------|
| 客户名称 | 文本 | ✓ |
| 国家/地区 | 文本 | — |
| 联系人姓名 | 文本 | — |
| 联系方式（电话/邮箱） | 文本 | — |
| 备注 | 文本 | — |
| 状态 | 启用 / 停用 | ✓ |

### States
| 场景 | 状态 |
|------|------|
| 列表为空 | 提示"暂无客户，请先新增" |
| 客户名重复 | 错误"已存在同名客户" |
| 停用有未结清账款的客户 | 警告"该客户存在未收款记录，停用后仍可在账款模块查看，是否继续？" |

## MVP Scope
- 产品新增、编辑、停用
- 用户新增、角色分配、停用
- 客户新增、编辑、停用
- 供应商新增、编辑、停用
- 四种角色：老板、财务、仓管、主管
- 用户登录（账号 + 密码）
