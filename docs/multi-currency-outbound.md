# 出库多币种支持（人民币 / 美元）

## Goal
出库业务分内销（人民币结算）和出口（美元结算）两种场景。当前出库记录只支持单一币种，无法准确记录美元订单的单价与金额，也导致美元订单的毛利计算与人民币采购成本混算后失真。本功能让出库记录支持币种选择，并在保留原始币种数据的前提下，通过汇率折算实现营收/毛利的统一汇总展示。

## User Flow

1. 用户（仓管/财务）进入"录入出库"页面，选择产品
2. 用户选择**币种**：人民币 / 美元
   - 选择人民币：流程与现状一致，无汇率相关字段
   - 选择美元：
     a. 系统自动调用汇率接口，获取当日人民币兑美元中间价，自动填入"汇率"输入框
     b. 用户可手动修改该汇率（如实际结汇价格不同）
     c. 若接口调用失败，汇率输入框留空，提示用户手动输入，**不阻塞出库录入流程**
3. 用户填写销售单价（按所选币种，如美元单价）
4. 系统基于单价、数量、汇率（如为美元）计算：
   - 原始币种金额（如美元总额）
   - 折算人民币金额（用于内部汇总）
5. 保存后，该笔出库记录、及其产生的应收账款，均带有 `currency`、`exchange_rate`（美元时）、原始币种金额、折算人民币金额

## Page Sections

- **产品选择**（沿用现有）
- **币种选择**（新增）：人民币 / 美元，单选
- **汇率输入**（新增，仅美元时显示）：
  - 自动预填当日汇率（来源：人行中间价，通过后台API获取）
  - 可编辑
  - 必填（美元记录不允许空汇率保存）
- **销售单价**（沿用现有，按所选币种录入）
- 数量、对手方、备注等字段不变

## States (loading / empty / error / success)

- **loading**：选择美元币种后，汇率输入框显示加载中状态，等待接口返回
- **empty / API失败**：接口调用失败或超时，汇率输入框清空并显示提示文案（如"自动获取汇率失败，请手动输入当日汇率"），不阻塞其他字段填写和保存
- **error**：美元记录未填汇率时，保存校验失败，提示"请填写汇率"
- **success**：保存成功后，出库记录列表中该条目按原始币种展示金额（如显示 $ 符号+美元金额），仪表盘汇总按折算人民币金额计入总数

## MVP Scope

- 出库记录支持人民币/美元两种币种（不考虑其他币种）
- 系统自动获取汇率默认值，允许手动覆盖
- 汇率来源：中国人民银行每日汇率中间价
- 应收账款继承出库记录的币种、汇率、原始金额、折算金额
- 仪表盘/报表：营收、毛利、应收账款汇总按折算人民币金额合并展示统一总数
- 出库记录明细页/列表仍保留原始币种数据展示（用于客户对账、开票依据）

## Later（本次不做）

- 多币种支持扩展到人民币/美元以外的其他币种
- 汇率历史查询、汇率走势展示
- 自动对接客户实际结汇价格（现汇买入价）而非中间价
- 汇兑损益单独科目记录与核算
- 入库/采购环节的多币种支持（当前采购成本假定恒为人民币，未涉及此次改动）

## 核心决策记录（供 project.md 引用）

- [2026-07-05] 出库支持人民币/美元双币种，理由：约40%出库业务为美元结算的出口订单，占比已需要统一营收视图
- [2026-07-05] 采用"系统自动获取汇率 + 允许手动修改"而非纯手动输入，理由：减少人工查询负担，同时保留应对API失败/实际结汇价差异的灵活性
- [2026-07-05] 汇率默认来源定为央行中间价，理由：数据源公开稳定、财务记账口径通用
- [2026-07-05] 汇总方式选择方案B（记录汇率、折算合并展示统一总数），而非分币种展示，理由：美元业务占比已达40%，管理层需要统一营收/毛利视图
- [2026-07-05] 原始币种数据必须完整保留，不能被折算金额取代，理由：客户对账、开票依据原始币种金额
