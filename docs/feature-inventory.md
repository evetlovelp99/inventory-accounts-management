# Feature: 仓库管理（入库 / 出库 / 库存查询）

## Goal
让仓管实时、准确地录入每一笔货物进出，系统自动维护各产品的当前余量，任何角色随时可查询准确的库存状态与历史流水。

---

## User Flow

### 入库录入
1. 进入「仓库」→「录入入库」
2. 填写字段：产品名称（选择或新增）、规格/单位、入库数量、采购单价、入库日期、供应商名称、备注（可选）
3. 可展开「生产信息（选填）」区块，填写：产地/蜂场、采集日期、检测报告编号/机构/日期、检测报告文件上传、保质期。用于后续人工导出给外部溯源系统使用，不影响正常入库流程
4. 提交 → 系统计算该批次总金额（数量 × 单价），更新库存余量
5. 返回入库记录列表，最新一条置顶

### 出库录入
1. 进入「仓库」→「录入出库」
2. 填写基本字段：产品名称（从现有库存中选）、币种（人民币/美元）、销售单价、出库日期、客户名称、备注（可选）
   - 若选择美元，系统自动带出当日汇率（人行中间价），可手动修改；汇率为必填项；若自动获取失败，汇率框留空，提示手动输入，不阻塞后续填写
3. 在「批次明细」区域添加出库行：
   - 每行选择一个入库批次，填写该批次的出库数量
   - 可点击「+ 添加批次」继续添加更多行，支持跨批次混发
   - 每行独立校验：该行出库数量不得超过所选批次的剩余余量
4. 系统实时汇总：所有行的出库数量合计、加权平均采购成本、预估总毛利
5. 提交 → 按各行分别扣减对应批次余量，整笔记录作为一条出库流水保存
6. 返回出库记录列表

### 库存查询
1. 进入「仓库」→「当前库存」
2. 看到所有产品的当前余量列表（含单位）
3. 点击某产品 → 查看该产品的完整入库/出库流水（时间倒序）
4. 可按日期范围筛选流水

## Page Sections

### 录入入库页
- 表单区：产品选择、数量、单价、日期、供应商、备注
- 自动计算显示：本批总金额
- 可折叠「生产信息（选填）」区块：产地、采集日期、检测编号/机构/日期、检测报告上传、保质期
- 提交按钮

### 录入出库页
- 表单区：产品选择（显示当前总余量）、币种选择（人民币/美元）、汇率（仅美元时显示，自动预填当日人行中间价，可手动编辑）、销售单价、日期、客户、备注
- 批次明细区：可添加多行，每行选择入库批次 + 填写数量；支持删除行；至少保留一行
- 每行行内校验：数量不得超过该批次余量，超量时行内红色报错
- 自动计算显示：总出库数量、本批总销售额、加权采购成本、预估总毛利
- 提交按钮

### 库存总览页
- 产品列表：产品名、规格、当前余量、单位、最后更新时间
- 搜索/筛选栏
- 点击行 → 进入该产品流水详情

### 流水详情页
- 产品基本信息
- 入库/出库记录列表（时间、类型、数量、单价、对手方）
- 日期范围筛选

## States

| 场景 | 状态 |
|------|------|
| 提交录入时 | Loading：按钮禁用，显示"提交中…" |
| 库存为空（新系统） | Empty：提示"暂无库存，请先录入入库记录" |
| 出库某行数量超过该批次余量 | Error：该行行内报错「出库数量不能超过该批次余量 XX 单位」|
| 出库明细无有效行 | Error：提示「请至少添加一行批次明细」|
| 美元记录未填汇率 | Error：提示「请填写汇率」|
| 汇率自动获取失败 | Error/Empty：汇率框留空，提示「自动获取汇率失败，请手动输入」|
| 网络/服务器异常 | Error：顶部提示"提交失败，请稍后重试"，数据不丢失 |
| 录入成功 | Success：提示"入库记录已保存"，自动跳回列表 |
| 产品搜索无结果 | Empty：提示"未找到匹配产品，可新增产品" |

---

## MVP Scope
- 入库录入（含产品、数量、采购单价、日期、供应商）
- 出库录入（含产品、币种、销售单价、日期、客户；批次明细支持多行跨批次混发）
- 每行批次独立超量校验
- 毛利按各批次采购成本加权汇总计算
- 库存总览列表
- 单产品流水查询
- 记录修改（保留原始日志）

> 出库多币种（人民币/美元）的详细规则（汇率来源、汇总方式、原始币种数据保留等）见 `docs/multi-currency-outbound.md`
