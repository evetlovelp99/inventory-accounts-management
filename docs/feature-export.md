# Feature: 导出对账单（Excel + PDF）

## Goal
让财务和老板能随时将库存流水、账款明细导出为规范的 Excel 或 PDF 文件，用于内部核账、打印存档，或发给客户/供应商确认签字。

---

## User Flow

### 场景一：导出库存流水报表
1. 进入「仓库」→「库存查询」或「流水记录」
2. 选择筛选条件：时间范围、产品（可多选）、类型（入库/出库/全部）
3. 点击「导出」→ 选择格式（Excel 或 PDF）
4. 浏览器自动下载文件

### 场景二：导出客户/供应商对账单
1. 进入「财务」→「应收账款」或「应付账款」
2. 点击某个客户/供应商 → 进入详情页
3. 选择时间范围
4. 点击「导出对账单」→ 选择格式（Excel 或 PDF）
5. 浏览器自动下载文件
6. （可选）打印后交给客户/供应商签字确认

### 场景三：导出月度/阶段性汇总报表（老板用）
1. 进入首页看板或专属「报表」入口
2. 选择时间范围（本月/上月/自定义）
3. 选择报表类型：入库汇总 / 出库汇总 / 盈亏概览 / 账款汇总
4. 点击「导出」→ 选择格式
5. 浏览器自动下载

---

## Page Sections

### 导出入口（各模块内嵌）
- 筛选条件区（时间范围选择器、产品/客户多选）
- 「导出 Excel」和「导出 PDF」两个按钮（或一个按钮展开选择）
- 预计导出条数提示（如「共 45 条记录」）

### PDF 对账单内容（给客户/供应商）
- 抬头：厂名、对方公司/个人名称、账单生成日期
- 明细表格：日期、品名、数量、单价、金额、备注
- 汇总行：合计金额、已付/已收金额、剩余欠款
- 底部：签字确认区域（空白留签字用）

### Excel 导出内容（内部核账）
- 原始数据每行一条，字段完整（含所有系统字段）
- 最后一行自动汇总合计
- 无合并单元格（方便二次加工）

## 导出报表类型一览

| 报表名称 | 主要使用者 | 格式 |
|----------|------------|------|
| 入库流水明细 | 财务、仓管 | Excel / PDF |
| 出库流水明细 | 财务、仓管 | Excel / PDF |
| 客户对账单 | 财务（发给客户） | PDF 为主 |
| 供应商对账单 | 财务（发给供应商） | PDF 为主 |
| 月度盈亏概览 | 老板 | Excel / PDF |
| 应收账款汇总 | 财务、老板 | Excel / PDF |
| 应付账款汇总 | 财务、老板 | Excel / PDF |

---

## States

| 场景 | 状态 |
|------|------|
| 无数据可导出（筛选条件下为空） | Error：「当前筛选条件下无数据，请调整时间范围」 |
| 导出生成中 | Loading：「正在生成文件…」按钮禁用 |
| 导出成功 | 浏览器自动下载，无需额外提示 |
| 导出失败（服务器异常） | Error：「导出失败，请稍后重试」 |

---

## 文件命名规范（自动生成）
- 入库流水：`入库记录_2025年1月.xlsx`
- 客户对账单：`对账单_张三_2025年1月.pdf`
- 月度盈亏：`盈亏概览_2025年1月.pdf`

---

## MVP Scope
- 入库流水导出（Excel + PDF）
- 出库流水导出（Excel + PDF）
- 客户对账单导出（PDF，含签字区域）
- 供应商对账单导出（PDF，含签字区域）
- 应收/应付账款汇总导出（Excel）
- 按时间范围筛选后导出
- 自动文件命名
