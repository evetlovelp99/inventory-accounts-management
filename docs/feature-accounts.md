# Feature: 账款管理（应收 / 应付）

## Goal
让财务清晰追踪每一笔客户赊账（应收）和欠供应商货款（应付），支持部分还款登记，随时可知当前总外债状况，避免账款靠记忆管理造成的遗漏和纠纷。

---

## User Flow

### 新增应收账款（客户赊账）
1. 出库录入时，仓管勾选"该笔货款未收"
2. 系统自动在「应收账款」中生成一条待收记录（关联对应出库单）
3. 财务也可手动在「财务」→「应收账款」→「新增」中创建记录

### 登记客户还款
1. 财务进入「财务」→「应收账款」
2. 找到对应客户记录，点击「登记还款」
3. 填写：还款金额、还款日期、备注
4. 支持部分还款 → 系统自动更新剩余欠款金额
5. 全额结清后，该记录状态变为「已结清」，移入历史

### 新增应付账款（欠供应商）
1. 入库录入时，仓管勾选"该批货款未付"
2. 系统自动在「应付账款」中生成一条待付记录（关联对应入库单）
3. 财务也可手动新增

### 登记付款给供应商
1. 财务进入「财务」→「应付账款」
2. 找到对应供应商记录，点击「登记付款」
3. 填写：付款金额、付款日期、备注
4. 支持部分付款 → 系统更新剩余应付金额
5. 结清后移入历史

---

## Page Sections

### 应收账款页
- 顶部汇总：应收总额（未结清）
- 客户列表：客户名、原始金额、已收金额、剩余欠款、最后更新日期、状态标签（未结清/部分收款/已结清）
- 筛选：按状态（未结清 / 已结清）、按客户名搜索
- 点击某客户 → 查看该客户所有欠款明细及还款历史

### 应付账款页
- 顶部汇总：应付总额（未结清）
- 供应商列表：同上结构，方向为应付
- 点击某供应商 → 查看欠款明细及付款历史

### 还款/付款登记弹窗
- 字段：金额、日期、备注
- 显示当前剩余待收/待付金额
- 确认按钮

### 账款详情页（单客户/单供应商）
- 关联的出库/入库单信息
- 完整收款/付款流水（时间倒序）

---

## States

| 场景 | 状态 |
|------|------|
| 无未结清账款 | Empty：分别显示"暂无未结清应收账款"/"暂无未结清应付账款" |
| 登记中 | Loading：按钮禁用 |
| 还款金额超过剩余欠款 | Error：行内提示"还款金额不能超过剩余欠款 XX 元" |
| 结清成功 | Success：提示"已标记为结清"，自动归入历史 |
| 提交失败 | Error：提示"保存失败，请重试"，输入内容保留 |

---

## MVP Scope
- 应收账款列表（未结清/已结清）
- 应付账款列表（未结清/已结清）
- 从入库/出库录入时一键关联生成账款记录
- 手动新增账款记录
- 部分还款/付款登记
- 剩余金额自动计算
- 应收/应付总额汇总显示
- 账款明细及流水查看
