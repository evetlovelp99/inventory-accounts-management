# Feature: 首页看板（经营概览）

## Goal
让老板和主管登录后第一屏就能掌握当前库存状况、资金往来概况和近期动态，无需逐个模块点进去查询。

---

## User Flow

1. 用户登录后自动进入首页看板
2. 一屏内看到所有关键数字（库存、账款、近期流水）
3. 点击任意数字卡片 → 跳转到对应模块的详细列表
4. 看板数据实时反映最新录入，无需手动刷新

---

## Page Sections

### 库存概况区
- 各产品当前余量（卡片或列表形式）
- 如有产品余量为零，高亮提示

### 账款概况区
- 应收总额（未结清）
- 应付总额（未结清）
- 两个数字均可点击下钻

### 本月经营概览区
- 本月入库总金额（采购支出）
- 本月出库总金额（销售收入）
- 本月毛利概算（出库总额 - 对应采购成本）
  - 注：毛利仅供参考，不含运营成本等

### 最近动态区
- 最近 10 笔操作记录（入库/出库/还款，时间倒序）
- 每条显示：时间、操作类型、产品/客户/供应商、金额

---

## States

| 场景 | 状态 |
|------|------|
| 全新系统无数据 | Empty：各区块显示"暂无数据，请开始录入" |
| 数据加载中 | Loading：各卡片显示占位骨架 |
| 数据加载失败 | Error：提示"数据加载失败，请刷新页面" |
| 正常显示 | Success：所有数字正常展示，可点击下钻 |

---

## MVP Scope
- 各产品当前余量展示
- 应收/应付总额展示（未结清）
- 本月入库金额、出库金额、毛利概算
- 最近 10 笔动态记录
- 点击数字下钻到对应模块
