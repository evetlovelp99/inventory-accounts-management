# User Flow

## 整体导航结构
系统分为三个主模块 + 系统设置，所有角色登录后根据权限看到对应入口：

```
登录
 └── 首页看板（库存总览 + 账款预警）
      ├── 仓库模块
      │    ├── 入库录入
      │    ├── 出库录入
      │    └── 库存查询
      ├── 财务模块
      │    ├── 应收账款（客户赊账）
      │    └── 应付账款（欠供应商）
      └── 系统设置（仅老板可见）
           ├── 产品管理
           ├── 用户管理
           ├── 客户管理
           └── 供应商管理
```

---

## 核心流程一：录入一笔入库

1. 仓管登录系统，进入「入库录入」
2. 选择产品（从已有品类中选，或由老板在设置中新增）
3. 填写：入库日期、数量/重量、采购单价、供应商（从已有供应商中选）、批次号
4. 确认提交 → 系统自动更新该产品库存余量
5. 若该批货存在赊账（欠供应商），财务同步在「应付账款」中新增一条记录

---

## 核心流程二：录入一笔出库（销售发货）

1. 仓管进入「出库录入」
2. 选择产品，填写：出库日期、数量/重量、销售单价、客户（从已有客户中选）
3. 选择对应入库批次（系统显示该批次剩余库存）
4. 确认提交 → 系统自动扣减库存余量，并计算本笔毛利
5. 若客户赊账未付，财务同步在「应收账款」中新增一条记录
6. 同一批货分多次发出时，每次单独录入一笔出库

---

## 核心流程三：追踪外债（应收/应付）

**应收（客户欠款）：**
1. 财务进入「应收账款」
2. 查看所有未结清客户列表及金额
3. 客户还款时，找到对应记录 → 点击「标记收款」→ 填写收款金额和日期
4. 支持部分收款，剩余欠款自动计算
5. 可导出对账单（Excel 或 PDF）

**应付（欠供应商）：**
1. 财务进入「应付账款」
2. 查看所有未结清供应商列表及金额
3. 付款后，找到对应记录 → 点击「标记付款」→ 填写付款金额和日期

---

## 核心流程四：查看首页看板（老板视角）

1. 老板登录后直接进入首页看板
2. 看板展示：
   - 各产品当前余量（是否低于警戒线）
   - 本月入库总金额 vs 出库总金额
   - 应收总额 / 应付总额
   - 最近10笔流水记录
3. 点击任意数字可下钻到对应明细列表

---

## 核心流程五：维护基础数据（老板）

1. 老板进入「系统设置」
2. 在产品管理中新增/编辑产品品类
3. 在用户管理中新增账号、分配角色
4. 在客户管理中新增/编辑客户信息
5. 在供应商管理中新增/编辑供应商信息
6. 客户和供应商停用后，不再出现在录入时的下拉选项中，但历史数据保留

---

## 错误与修正流程

- 录入错误时，仓管/财务可直接修改记录
- 系统自动保留操作日志（修改前后的值、操作人、时间）
- MVP 阶段：无需审批流，日志自动记录即可
