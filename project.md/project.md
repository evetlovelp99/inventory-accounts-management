## 关键决策记录

| 决策 | 原因 |
|------|------|
| 部署在国内云服务器（阿里云/腾讯云） | 厂里无硬件条件；云服务器是独立租用的机器，数据安全可控，≠ 小程序/SaaS 平台 |
| Web 系统而非小程序 | 多角色、权限控制、规范操作、可导出对账单 |
| 技术栈：React + Ant Design + Spring Boot + MySQL | 前后端分离；Ant Design 适合企业内部系统；Spring Boot 国内生态成熟；Cursor 辅助开发 |
| MVP 不做审批流 | 团队规模小，靠角色权限控制即可，避免过度复杂 |
| 出库关联应收、入库关联应付 | 在录入货物时顺带处理账款，减少财务二次录入 |
| 毛利按批次对应计算（非 FIFO） | 每笔出库直接绑定某次入库的采购价，逻辑清晰直观 |
| 导出同时支持 Excel 和 PDF | Excel 用于内部核账，PDF 用于打印给客户/供应商签字确认 |
| 客户管理和供应商管理放在系统设置内 | MVP 阶段客户数量少，无需单独导航项；后期可拆出 |
| 出库支持人民币/美元双币种，记录汇率折算合并汇总 | 约40%出库为美元出口订单，需统一营收/毛利视图；系统自动获取央行中间价作默认汇率，允许手动修改，原始币种数据完整保留用于对账开票 |
