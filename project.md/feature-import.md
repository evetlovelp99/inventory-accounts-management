# Feature: 历史数据导入（Excel）

## Goal
让财务或老板能将过去手工记录的 Excel 历史账目一次性导入系统，避免手动逐条录入的巨大工作量，确保系统上线后历史数据完整可查。

---

## User Flow

1. 老板/财务进入「设置」→「数据导入」
2. 下载系统提供的**标准导入模板**（Excel 格式，含字段说明）
3. 按模板格式整理历史数据，填入 Excel
4. 回到导入页面，上传填好的 Excel 文件
5. 系统解析文件，展示**预览列表**（前 20 条），标出识别异常的行
6. 用户确认预览无误 → 点击「确认导入」
7. 系统后台处理，完成后提示成功条数 / 失败条数
8. 失败的行可下载「错误报告」，修改后重新上传该部分数据

---

## Page Sections

### 导入引导页
- 步骤说明（下载模板 → 填写 → 上传 → 确认）
- 「下载标准模板」按钮（分三类：入库历史、出库历史、账款历史）
- 上传区域（拖拽或点击选择文件，仅支持 .xlsx）
- 注意事项说明（日期格式、必填字段、不得合并单元格等）

### 预览确认页
- 表格预览：展示解析出的前 20 条记录
- 异常行高亮标红，鼠标悬停显示错误原因
- 汇总信息：共识别 N 条，其中 X 条有问题
- 「返回修改」和「确认导入（跳过错误行）」两个按钮

### 导入结果页
- 成功导入 N 条
- 跳过 / 失败 M 条
- 「下载错误报告」按钮（若有失败行）
- 「查看已导入数据」按钮

## 导入模板字段说明

### 入库历史模板
| 字段 | 是否必填 | 说明 |
|------|----------|------|
| 入库日期 | ✓ | 格式：YYYY-MM-DD |
| 产品名称 | ✓ | 需与系统内产品名一致 |
| 数量 | ✓ | 数字，不含单位 |
| 单位 | ✓ | 如：公斤、桶 |
| 采购单价 | ✓ | 数字，单位：元 |
| 供应商名称 | ✓ | 自由填写 |
| 是否已付款 | ✓ | 填"是"或"否" |
| 备注 | — | 自由填写 |

### 出库历史模板
| 字段 | 是否必填 | 说明 |
|------|----------|------|
| 出库日期 | ✓ | 格式：YYYY-MM-DD |
| 产品名称 | ✓ | 需与系统内产品名一致 |
| 数量 | ✓ | 数字 |
| 单位 | ✓ | |
| 销售单价 | ✓ | 数字，单位：元 |
| 客户名称 | ✓ | 自由填写 |
| 是否已收款 | ✓ | 填"是"或"否" |
| 关联入库批次编号 | — | 若能对应具体入库批次则填，否则留空 |
| 备注 | — | 自由填写 |

### 账款历史模板
| 字段 | 是否必填 | 说明 |
|------|----------|------|
| 账款类型 | ✓ | 填"应收"或"应付" |
| 对方名称 | ✓ | 客户名或供应商名 |
| 原始金额 | ✓ | 数字，单位：元 |
| 已收/已付金额 | ✓ | 数字，未收付填 0 |
| 发生日期 | ✓ | 格式：YYYY-MM-DD |
| 备注 | — | 自由填写 |

## States

| 场景 | 状态 |
|------|------|
| 未上传文件 | 默认：显示上传引导区 |
| 文件格式不对（非 .xlsx） | Error：「请上传 .xlsx 格式文件」 |
| 文件解析中 | Loading：「正在读取文件…」 |
| 所有行都有问题 | Error：「未能识别有效数据，请检查是否使用了标准模板」 |
| 部分行有问题 | Warning：预览页标红，提示可跳过错误行继续导入 |
| 导入处理中 | Loading：「正在导入，请勿关闭页面…」进度提示 |
| 导入完成（全部成功） | Success：「成功导入 N 条记录」 |
| 导入完成（有失败） | Success + Warning：「成功 N 条，失败 M 条，可下载错误报告」 |

---

## MVP Scope
- 三类模板下载（入库、出库、账款）
- 上传 Excel 文件解析预览
- 异常行标红提示
- 跳过错误行、导入有效行
- 下载错误报告
- 导入后数据自动计入库存余量和账款
